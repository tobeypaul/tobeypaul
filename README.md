## 📌 Featured Project

### ⚡ CamPower — Public Platform Website

[View Repository →](https://github.com/tobeypaul/cam-power-vitrine)

A public-facing website for the CamPower platform built with a lightweight, static-first architecture.

**Tech**

`Astro` · `TypeScript` · `HTML` · `CSS`

**Highlights**

- Built with Astro and TypeScript
- 11 routed pages
- Static rendering by default
- Component-based frontend structure
- Content separated from presentation logic
- Minimal client-side JavaScript
- Responsive navigation
- Optimized image delivery
- Open Graph and canonical metadata support
- TypeScript validation and production build workflow
- Clear separation between marketing site and application runtime

The project intentionally avoids unnecessary client-side hydration, using static rendering wherever possible.
